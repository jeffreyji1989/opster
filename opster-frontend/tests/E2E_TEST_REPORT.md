## 测试执行步骤

### 1. 启动前端开发服务器

```bash
cd opster-frontend
npm run dev
```

### 2. 启动后端服务

```bash
cd opster-backend
mvn spring-boot:run
```

### 3. 运行测试

```bash
# 运行所有测试
npx playwright test

# 仅运行服务发版测试
npx playwright test tests/e2e/service-deploy.spec.ts

# 仅运行发版记录测试
npx playwright test tests/e2e/deployment-record.spec.ts

# 有头模式（可视化执行）
npx playwright test --headed

# 调试模式
npx playwright test --debug
```

### 4. 查看报告

```bash
npx playwright show-report
```
