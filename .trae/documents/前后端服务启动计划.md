# 前后端服务启动计划

## 分析当前状态
- 前端：Vue 3 + Vite 项目，启动命令 `npm run dev`
- 后端：Spring Boot 3.5.9 项目，启动命令 `mvn spring-boot:run`
- 后端 Java 版本已改为 17，解决了之前的编译问题
- 已集成 Spring AI Alibaba 框架

## 启动步骤

### 1. 前端服务启动
- 进入 `opster-frontend` 目录
- 检查并安装依赖（如果未安装）：`npm install`
- 启动开发服务器：`npm run dev`
- 验证服务是否在 http://localhost:5173/ 正常运行

### 2. 后端服务启动
- 进入 `opster-backend` 目录
- 编译并启动服务：`mvn spring-boot:run`
- 验证服务是否在 http://localhost:8080 正常运行
- 检查日志确认 Spring AI Alibaba 集成是否正常

### 3. 服务验证
- 访问前端页面，检查是否能正常连接后端
- 测试核心功能，确保服务运行正常

## 预期结果
- 前端服务成功启动，可访问 Web 界面
- 后端服务成功启动，提供 API 接口
- 前后端通信正常，功能完整可用
