# 实现计划

## 一、项目管理和服务器管理状态开关功能

### 1. 项目管理前端修改
- 修改 `Project.vue` 组件，在表格中添加"状态"列，使用开关组件显示和控制状态
- 添加 `handleToggleStatus` 函数，处理开关状态切换并更新后端数据
- 在表单中添加状态开关控件
- 确保表单初始化时状态字段有默认值

### 2. 服务器管理前端修改
- 修改 `Server.vue` 组件，在表格中添加"状态"列，使用开关组件显示和控制状态
- 添加 `handleToggleStatus` 函数，处理开关状态切换并更新后端数据
- 在表单中添加状态开关控件
- 确保表单初始化时状态字段有默认值

## 二、服务监控线程实现

### 1. 后端监控服务实现
- 创建 `ServiceMonitorService` 类，实现 `InitializingBean` 接口
- 在 `afterPropertiesSet` 方法中启动定时任务线程
- 使用 `@Scheduled` 注解配置定时任务，每隔1分钟执行一次
- 实现服务状态检查逻辑：
  - 查询所有启用状态为1的服务
  - 遍历服务列表，根据服务的IP、端口和监控地址判断服务是否正常
  - 使用HTTP请求或Socket连接检查服务可用性
  - 更新服务的运行状态（1-正常，2-异常）

### 2. 监控逻辑
- 优先使用监控地址（如果存在）进行健康检查
- 如果没有监控地址，使用IP+端口进行基本连接检查
- 设置合理的超时时间，避免监控线程阻塞
- 记录监控日志，便于排查问题

## 三、技术实现细节

### 1. 前端实现
- 使用 Element Plus 的 `el-switch` 组件
- 配置 `active-value="1"` 和 `inactive-value="0"`
- 实现实时状态更新，确保用户操作能立即反映到后端

### 2. 后端实现
- 使用 Spring Boot 的 `@Scheduled` 注解实现定时任务
- 配置线程池，确保监控任务不影响主线程
- 实现健壮的异常处理，确保监控线程不会因单个服务检查失败而停止
- 使用 `RestTemplate` 或 `HttpClient` 进行HTTP健康检查
- 使用 `Socket` 进行TCP端口连接检查

## 六、实现效果

1. **项目管理和服务器管理**：用户可以通过开关直接控制项目和服务器的启用/禁用状态
2. **服务监控**：系统会自动监控启用状态的服务，每隔1分钟检查一次服务状态并更新
3. **状态显示**：服务管理页面会实时显示服务的运行状态（正常/异常）
4. **可靠性**：监控逻辑健壮，能处理各种异常情况

此实现方案完全符合用户需求，提供了直观的状态管理界面和自动的服务监控功能。
